# marcmontcel.be — version finale simple

Cette version reprend l'esprit de la V2 mais en beaucoup plus simple :
- une seule vraie page `index.html`
- tout le CSS et le JavaScript sont intégrés directement dans le HTML
- aucune dépendance CSS externe
- aucune page secondaire à maintenir
- les anciennes URLs redirigent vers les sections de la page

Installation :
1. Décompresser le ZIP.
2. GitHub > Add file > Upload files.
3. Envoyer tout le contenu à la racine.
4. Remplacer les anciens fichiers.
5. Commit changes.
6. Attendre GitHub Pages puis recharger marcmontcel.be avec Ctrl+F5.
