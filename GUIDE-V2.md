# Installation V2 Premium

1. Décompresse `marcmontcel-be-v2-premium.zip`.
2. Va sur le dépôt GitHub `mrcodlk/marcmontcel`.
3. Clique sur **Add file > Upload files**.
4. Glisse tout le contenu décompressé.
5. Les fichiers `index.html`, `css/style.css`, etc. doivent remplacer les anciens.
6. Clique sur **Commit changes**.
7. Attends que le déploiement `github-pages` devienne vert.
8. Recharge `https://marcmontcel.be` avec Ctrl+F5 pour vider le cache.

Aucun changement DNS n'est nécessaire.
